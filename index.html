$ ls ./projetos

bus.io — Gestão de assentos de ônibus fretados

API e interface web para controlar em tempo real a ocupação de ônibus fretados que levam colaboradores até o Porto do Açu: mapa de assentos interativo, fluxo de hora extra com confirmação e login via Active Directory.

  • FastAPI + SQLAlchemy 2 + MySQL; frontend com HTMX, Alpine.js e Tailwind
  • Autenticação LDAP com 3 níveis de acesso por grupo do AD
  • Docker Compose (app + banco), sem credenciais hardcoded

→ github.com/tuliodutra27/bus.io

uniasselvi-sjb — Gestão de matrículas, leads e mensalidades

Sistema web em Flask para o polo EAD de Uniasselvi em São João da Barra: identifica alunos novos comparando CSVs de inscrição por CPF, consolida alunos matriculados e situação de mensalidades com filtros e dashboards.

  • Flask 3.1 + SQLite + pandas, com detecção automática de colunas em múltiplos formatos de CSV
  • Autenticação com papéis (admin/usuário) e log de auditoria de ações sensíveis
  • Deploy via Docker Compose

→ github.com/tuliodutra27/uniasselvi-sjb

Indicadores RH — Comparação automática de efetivo

Sistema web que compara automaticamente as planilhas semanais de colaboradores, detectando admissões, desligamentos e mudanças de cargo/departamento/gestor, com exportação de relatório em Excel.

  • Flask + pandas/openpyxl para leitura e comparação de planilhas .xlsx
  • Autenticação via Active Directory (ldap3) com múltiplos grupos
  • Dashboard com histórico de comparações e export Excel colorido por tipo de evento

→ github.com/tuliodutra27/Indicadores-RH

Plugin Permissões de Pastas — GLPI

Plugin PHP para GLPI 10 que cruza ACLs NTFS de um file server Windows com a membership do Active Directory, mostrando a gestores quem tem acesso a quais pastas.

  • Coletor PowerShell (Get-Acl, Get-ADGroupMember) integrado via API REST em PHP
  • Árvore de pastas interativa com classificação automática de permissões
  • Integração nativa ao sistema de direitos/perfis do GLPI

→ github.com/tuliodutra27/plugin-permissoes

Plugin Termos — GLPI

Plugin PHP para geração automática de termos de responsabilidade em PDF para ativos cadastrados no GLPI (computadores, monitores, telefones, rádios e periféricos).

  • Geração de PDF com TCPDF; cláusulas e cabeçalho configuráveis via CRUD
  • Campos customizados extraídos via tags no comentário de cada ativo

→ github.com/tuliodutra27/plugin-termos
